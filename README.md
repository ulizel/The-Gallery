# The Gallery

A single-file web app that creates divider images for your phone's photo library. Pick a trip date, choose how many images, add a title, and export. Each image is stamped with a capture time starting at 00:00:00, one second apart, so the set sits right before your trip photos in iPhone and Android galleries.

Everything runs in your browser. Nothing is uploaded anywhere.

## Use it
Open the hosted page on your phone and choose Add to Home Screen.
https://ulizel.github.io/The-Gallery/

## Or host your own
Fork this repo, then Settings → Pages → Deploy from branch → `main` / root.
